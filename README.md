# WanderLust 🌍

A full-stack web application for discovering, creating, and reviewing travel destinations. Users can browse listings, create their own destinations, upload images, leave reviews, and manage their listings securely through authentication.

🚀 **This is my first full-stack backend project built after learning Node.js, Express.js, MongoDB, and EJS.**

---

## ✨ Features

- 🔐 User Authentication (Signup/Login/Logout)
- 🏡 Create, Edit & Delete Listings
- 📍 Browse travel destinations
- 📝 Add and Delete Reviews
- ⭐ Rating system for reviews
- 🖼️ Image upload support with Cloudinary
- 👤 Authorization (Only listing owners can edit or delete their listings)
- 💬 Flash messages for success and error handling
- 🛡️ Server-side validation using Joi
- 📱 Responsive user interface with Bootstrap
